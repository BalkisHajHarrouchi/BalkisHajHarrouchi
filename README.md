## Featured Project

<table>
<tr>
<td valign="top">

### Intelligent Opportunity Management Platform

**Final-Year Engineering Project · EY Tunisia**

An AI-powered platform designed to support the analysis, qualification, and management of business opportunities.

#### Core Capabilities

- Opportunity document extraction and analysis
- Consultant CV parsing and structuring
- Multilingual CV enrichment and adaptation
- Consultant-to-opportunity matching
- Mission reference management
- Semantic and hybrid search
- AI-assisted recommendations
- Agentic CV adaptation workflows
- Business dashboards and indicators
- Role-based access control and auditability

#### Engineering Highlights

- Built processing pipelines for PDF, DOCX, and PPTX documents
- Structured consultant profiles, experiences, missions, and skills
- Implemented hybrid retrieval with embeddings and full-text search
- Designed orchestrated workflows using specialized AI agents
- Integrated LLMs for extraction, analysis, generation, and recommendations
- Added deterministic validation to reduce unsupported AI outputs
- Developed secure APIs with granular role-based permissions
- Implemented asynchronous processing using Redis and ARQ
- Designed relational and vector-based data architectures
- Containerized the platform and its services using Docker

> Some implementation details and source code remain private because the platform was developed in a professional context.
