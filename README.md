<h2>Featured Project</h2>

<h3>Intelligent Opportunity Management Platform</h3>

<p><strong>Final-Year Engineering Project · EY Tunisia</strong></p>

<p>
  An AI-powered platform designed to support the analysis, qualification, and management of business opportunities.
</p>

<h4>Core Capabilities</h4>

<ul>
  <li>Opportunity document extraction and analysis</li>
  <li>Consultant CV parsing and structuring</li>
  <li>Multilingual CV enrichment and adaptation</li>
  <li>Consultant-to-opportunity matching</li>
  <li>Mission reference management</li>
  <li>Semantic and hybrid search</li>
  <li>AI-assisted recommendations</li>
  <li>Agentic CV adaptation workflows</li>
  <li>Business dashboards and indicators</li>
  <li>Role-based access control and auditability</li>
</ul>

<h4>Engineering Highlights</h4>

<ul>
  <li>Built processing pipelines for PDF, DOCX, and PPTX documents</li>
  <li>Structured consultant profiles, experiences, missions, and skills</li>
  <li>Implemented hybrid retrieval with embeddings and full-text search</li>
  <li>Designed orchestrated workflows using specialized AI agents</li>
  <li>Integrated LLMs for extraction, analysis, generation, and recommendations</li>
  <li>Added deterministic validation to reduce unsupported AI outputs</li>
  <li>Developed secure APIs with granular role-based permissions</li>
  <li>Implemented asynchronous processing using Redis and ARQ</li>
  <li>Designed relational and vector-based data architectures</li>
  <li>Containerized the platform and its services using Docker</li>
</ul>

<blockquote>
  Some implementation details and source code remain private because the platform was developed in a professional context.
